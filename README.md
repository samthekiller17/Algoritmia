## Sesión 1: Pensamiento algorítmico

La carpeta [`algoritmia-s1`](./algoritmia-s1) reúne ejercicios introductorios para representar procesos paso a paso y construir programas básicos en PSeInt.

### Ejercicios documentados

- `tinto.md`: instrucciones para preparar un tinto.
- `preparar-limonada.md`: algoritmo para preparar limonada.
- `cruzar-la-quebrada.md`: solución del problema del campesino, el perro, la gallina y el maíz.

### Programas en PSeInt

| Archivo | Descripción |
|---|---|
| `01_Saludo.psc` | Solicita un nombre y muestra un saludo. |
| `02_EdadEnDias.psc` | Calcula los días vividos de manera aproximada. |
| `03_Propinas.psc` | Calcula propina, total de la cuenta y valor por persona. |
| `04_PromedioNotas.psc` | Calcula el promedio de tres notas. |
| `05_positivo-negativo-cero.psc` | Determina si un número es positivo, negativo o cero. |
| `06_AreaRectangulo.psc` | Calcula el área de un rectángulo a partir de su base y altura. |

## Cómo ejecutar los programas

1. Instala [PSeInt](https://pseint.sourceforge.net/).
2. Abre cualquier archivo con extensión `.psc`.
3. Ejecuta el programa con la tecla **F9** o el botón verde de ejecución.
4. Ingresa los datos solicitados en pantalla.
