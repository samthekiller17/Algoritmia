# Algoritmia

Ejercicios, evidencias y soluciones desarrolladas durante el módulo de Algoritmia de Riwi usando PSeInt.

## Contenido

| Sesión | Tema | Programas y ejercicios |
|---|---|---|
| [Sesión 1](./algoritmia-s1) | Pensamiento algorítmico | Algoritmos cotidianos, saludo, edad en días, propinas, promedio, clasificación de números y área de rectángulo |
| [Sesión 2](./sesion-02) | Lógica y decisiones | Registro, validación de edad, parqueadero, semáforo de inventario y año bisiesto |
| [Sesión 3](./sesion-03) | Repetir y descomponer | Cajero de parqueadero, calificaciones, pirámide, factura de restaurante y árbol de componentes |

---

## Sesión 1: Pensamiento algorítmico

Carpeta: [`algoritmia-s1`](./algoritmia-s1)

Introduce la creación de algoritmos paso a paso y programas básicos en PSeInt.

| Archivo | Descripción |
|---|---|
| `tinto.md` | Instrucciones para preparar un tinto. |
| `preparar-limonada.md` | Algoritmo para preparar limonada. |
| `cruzar-la-quebrada.md` | Solución al problema del campesino, el perro, la gallina y el maíz. |
| `01_Saludo.psc` | Solicita un nombre y muestra un saludo. |
| `02_EdadEnDias.psc` | Calcula los días vividos de manera aproximada. |
| `03_Propinas.psc` | Calcula propina, total de la cuenta y valor por persona. |
| `04_PromedioNotas.psc` | Calcula el promedio de tres notas. |
| `05_positivo-negativo-cero.psc` | Clasifica un número como positivo, negativo o cero. |
| `06_AreaRectangulo.psc` | Calcula el área de un rectángulo. |

---

## Sesión 2: Lógica y decisiones

Carpeta: [`sesion-02`](./sesion-02)

Aplica operadores lógicos, condiciones, tablas de verdad y tablas de decisión.

| Archivo | Descripción |
|---|---|
| `01_ValidarRegistro.psc` | Permite el registro a usuarios de 14 años o más que acepten los términos. |
| `02_ValidarEdad.psc` | Valida edades entre 0 y 120 aplicando la Ley de De Morgan. |
| `03_Parqueadero.psc` | Calcula tarifas de parqueadero, tope diario y descuento por factura. |
| `04_Semaforo.psc` | Clasifica el inventario en rojo, amarillo o verde según las unidades disponibles. |
| `05_Bisiesto.psc` | Determina si un año es bisiesto. |

El README de esta sesión incluye tablas de verdad, tablas de decisión, casos borde y pruebas de escritorio.

---

## Sesión 3: Repetir y descomponer

Carpeta: [`sesion-03`](./sesion-03)

Trabaja ciclos, acumuladores, contadores, ciclos anidados y subprocesos.

| Archivo | Descripción |
|---|---|
| `01_CajeroParqueadero.psc` | Registra carros y recauda pagos hasta recibir el valor centinela `0`. |
| `02_Calificaciones.psc` | Calcula estadísticas de cinco notas: promedio, aprobados, máxima y mínima. |
| `03_Piramide.psc` | Dibuja una pirámide de asteriscos usando ciclos anidados. |
| `04_FacturaRestaurante.psc` | Genera una factura con impuesto al consumo y propina mediante subprocesos. |

También incluye un árbol de componentes de una tienda de ropa en línea para relacionar ciclos y subprocesos con la estructura de una página web.

---

## Cómo ejecutar los programas

1. Instala [PSeInt](https://pseint.sourceforge.net/).
2. Abre cualquier archivo con extensión `.psc`.
3. Ejecuta el programa con **F9** o el botón verde de ejecución.
4. Ingresa los datos solicitados en pantalla.
