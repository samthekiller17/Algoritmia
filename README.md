# Algoritmia

Ejercicios y evidencias del módulo de Algoritmia (Riwi), hechos en PSeInt.

## Contenido

| Carpeta | Tema | Programas |
|---|---|---|
| [`algoritmia-s1`](./algoritmia-s1) | Sesión 1: Pensamiento algorítmico | Ver carpeta |
| [`sesion-02`](./sesion-02) | Sesión 2: Lógica y decisiones | Registro, validación de edad, parqueadero, semáforo y año bisiesto |
| [`sesion-03`](./sesion-03) | Sesión 3: Repetir y descomponer | Cajero del parqueadero, calificaciones, pirámide y factura de restaurante |

Cada carpeta tiene sus archivos `.psc` y un `README.md` con las tablas de verdad, de decisión y de traza, además de las pruebas de escritorio.

## Cómo ejecutar

1. Instala [PSeInt](https://pseint.sourceforge.net/).
2. Abre cualquier archivo `.psc`.
3. Presiona **F9** (o el botón verde de ejecutar).
